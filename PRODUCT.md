# DesignScout — Product Context

## What it is
An MCP server and CLI tool that gives AI coding agents (Claude Code) the ability to browse websites, capture and analyze visual design, and turn that inspiration into production code.

## Surface type
Brand (open source project landing page, documentation, GitHub presence).

## Audience
Frontend developers, design engineers, and AI-assisted coding enthusiasts who use Claude Code. Technical, opinionated about design, and allergic to AI-generated-looking output.

## Voice
Direct, technical, confident. No hype, no buzzwords. Show what it does, not what it promises. The tool speaks for itself.

## Anti-references
- Generic SaaS landing pages with purple gradients and Inter font
- AI-generated UI with icon tiles above every heading
- Cookie-cutter developer tool sites that all look the same

## Brand lane
Developer tooling with craft. Think Linear's precision meets Vercel's confidence — but with a neubrutalist edge that says "this was designed by a human."
